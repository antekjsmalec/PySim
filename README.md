# Ball Pit Sim
A simple pygame powered physics simulator :]

Fun to play around with. Orignally meant to have complex polygon collsions but I didn't have time so only circles  :(

## Features
- Heavy 'bowling' balls (right click)
- Light 'baloon' balls (left click)
- Random size , colour and mass balls (middle click)
- Ability to freeze the simulation (spacebar)

## Running .exe
Simply download the .exe file and run it.

## Running in Python
Make sure pygame-ce and python is installed. Pyhton can be installed from python.org and pygame- ce can be installed using 'pip install pygame-ce'
